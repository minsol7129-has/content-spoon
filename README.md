# 콘텐츠 한 스푼 🥄

인스타에 뭘 올릴지 고민될 때, 취향 태그를 1~2개 고르면 다른 사람들이 찍은 릴스와 오늘의 콘텐츠 기획을 같이 보여주는 한 페이지짜리 웹사이트.

## 기능
- 태그 16개(요리, 여행, 패션 …) 중 1~2개 선택 → 태그마다 콘텐츠 유형 카드 1개
- 🎬 이렇게 찍었어요: 인스타 공식 임베드(퍼가기)로 공개 릴스를 보여줌. 사진을 복사해 저장하지 않음
- 📝 기획을 도와드립니다!: 오늘의 기획(제목, 첫 3초 멘트, 구성 3단계, 캡션, 팁)
- 맨 위에 오늘의 테마 표시

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 전부. 태그 목록(`TAGS`)과 콘텐츠 유형(`CONTENTS`)도 여기 있음 |
| `daily.js` | 오늘의 기획 데이터. `window.DAILY`(오늘), `window.DAILY_PREV`(어제) |
| `reels.js` | 유형별 공개 릴스 게시물 코드 목록 (`window.REELS`, 유형마다 최대 20개) |

## 매일 바뀌는 것
- **기획 (9시):** Claude 데스크톱 앱의 예약 작업이 매일 아침 8시 30분쯤 `daily.js`를 새로 써서 이 저장소에 push한다. 사이트는 9시 전에는 `DAILY_PREV`, 9시 정각부터는 `DAILY`를 보여준다.
- **영상 (매주 월요일 10시):** 사이트가 `reels.js` 목록(유형마다 20개)을 섞어 5개씩 4묶음으로 나누고, 한 묶음을 일주일 동안 보여준 뒤 매주 월요일 10시에 다음 묶음으로 바꾼다. 몇 주차인지는 `REELS_START`(1주차 월요일)부터 센다.
- **새 영상 (매월):** 매월 1일 10시에 알림 예약 작업이 "영상 새로 채울 때"라고 알려준다. 그때 Claude와 함께 새 20개를 모아 `REELS`를 갈고 `REELS_START`를 그 주 월요일로 바꾼다.
- **영상 정리:** 같은 예약 작업이 매일 로그인 없이 임베드를 확인해서, 지워졌거나 비공개가 된 영상을 `reels.js`에서 뺀다. 새 영상은 자동으로 모으지 않는다(인스타 계정 보호).

빌드 과정은 없다. `index.html`을 브라우저로 열면 바로 보인다.
